# Establish Initial Themes

the foler './theme-references' provides an initial example of the look and for this application. it will mostly be a dashboard based experience. 

the overall goal is to allow the user to switch between color schemes from a menu. the components will be the same, however we support the ability for the user to select a color schema as follows:
* 'white' closely matches what is in the example
* 'blue' insteat of a predominant white background, we use shages of blue reflected in the 'example2.png' image
* 'dark' would be the third variant, where this is essentially a 'dark mode' experience. where primarily back and shaved of grey come into play.
